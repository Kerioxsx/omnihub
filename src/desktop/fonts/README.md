# Fonts

`minecraft.ttf` — "Minecraft" by Craftron Gaming, a free font (listed as
100% free on DaFont). It is used for headings in the Minecraft theme. It is
the author's work and not covered by OmniHub's MIT licence.

OmniHub is not affiliated with Mojang or Microsoft. The Minecraft theme's
blocks, clouds and sky are drawn by OmniHub's own code; item pictures come
only from a pack the user chooses on their own PC and are never shipped.
